# 果园设备调查 · 答卷清洗

用于果园设备调查的答卷清洗网页：上传带户号的答卷 CSV 与 JSON 跳题表，系统按跳题规则推演每户路径，只保留走到题目上的答案；逐户改答；下载给分析员的 CSV。

## 功能

- **导入**：CSV + JSON 跳题表，一次导入形成一个批次。CSV 自动识别户号列（`户号`、`household_no` 等，找不到时用第一列），支持 UTF-8 / GBK。
- **跳题**：单选题的某个选项指定了跳转题号就跳到该题；该选项没有指定跳转就按题序进入下一题；遇到空答立即停止。
- **拒答续答**：CSV 可加一列「拒答续答」，每户至多填一处，写法 `Q1>Q5`（支持全角 `＞`），表示 Q1 被拒答（答案格留空）后访问员接着问了 Q5。拒答题必须是按原规则走到、且留空的单选题，去向必须是其某个合法选项的下一题；记录有误时报出户号和原因，整批不入库。
- **只采用走到题目的值**：被跳过、在第一条空答之后、或在拒答续答点之前未走到的答案不会导入（即使 CSV 里填了值）。
- **逐户改答**：按到达每题前经过的题目序列（路径）分别保存答案。两条路径走到同一道题（例如最后共用的费用题）时互不干扰；切回原路径即恢复该路径上填过的值。改答页会列出其他路径上已保存的答案供核对。
- **拒答处理**：逐户页显示拒答题与去向，可补填实际选项（按该选项重新推演）或勾选清除记录（本题保持留空、路径在此停止）。补填后路径相同则沿用已有后答，改走别支则只读新路径上的答案；改前题绕开拒答时，切回原路径会恢复拒答记录和后答。
- **下载**：CSV 含户号、当前路径、已答题数、每道题在当前路径上的有效答案、首个漏答题及题干；带「拒答续答」列导入的批次会保留该列，只填当前路径上仍生效的记录。拒答题答案格留空，不计入已答题数，也不报作首个漏答题。
- **保存失败回退**：一次保存是一个 SQLite 事务；失败时网页与下载都继续沿用上次保存的答卷（含拒答记录），并提示错误。

## 启动

```bash
docker compose up --build
# 打开 http://localhost:8000
```

数据保存在命名卷 `survey-data`（容器内 `/data/survey.sqlite3`）。可用环境变量调整：

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `SURVEY_PORT` | `8000` | 宿主机端口 |
| `SURVEY_SECRET` | `change-me-in-production` | Flask session 密钥，请在生产环境修改 |
| `SURVEY_DB` | `/data/survey.sqlite3` | 容器内数据库路径 |

不用 Docker 也可以直接运行：

```bash
pip install -r requirements-dev.txt
cd app
SURVEY_DB=../data/survey.sqlite3 python3 -m main
```

## 答卷 CSV

第一行是表头，必须含户号列；其余每列是一道题。列名写成 `题号 题干`（如 `Q1 设备来源`）、只写题号、或只写题干都可以匹配到 JSON 里的题号。

```csv
户号,Q1 设备来源,Q2 自购设备类型,Q3 自购台数,Q4 是否享受购置补贴,Q5 租赁方式,Q6 租赁台数,Q7 年费用合计（元）
H001,自购,喷药机,2,无,,,12000
H002,租赁,喷药机,2,有,按年整租,3,8000
```

示例见 `examples/answers.csv`。户号重复时保留第一行并给出提示。

### 拒答续答列

在答卷 CSV 中加一列，表头为「拒答续答」（没有这一列时行为与原来完全一致）。每一户至多填一处，格式为 `拒答题号>续答题号`，全角 `＞` 也可以：

```csv
户号,Q1 设备来源,Q5 租赁方式,Q6 租赁台数,Q7 年费用,拒答续答
H007,,按年整租,2,7000,Q1>Q5
```

校验规则（任一不满足都会报出户号和原因，**整批不入库**）：

- 拒答题必须是**单选题**，且该户按跳题规则原本就会走到这道题；
- 拒答题的答案格必须**留空**；
- 去向必须是该题某个合法选项的下一题：选项有跳转就取跳转目标，没有跳转就取题序的下一题。

导入后从记录的下一题继续推演，之后再遇到普通空答仍会照常停止。拒答题答案留空、不计入已答题数，也不会被报成首个漏答题。示例见 `examples/answers.csv` 的 H007（运行 `python3 -I examples/preview.py` 可查看其路径）。

## JSON 跳题表

支持四种写法，任选其一。

1. 完整题目列表（顺序即题序）：

```json
[
  {"id": "Q1", "title": "设备来源", "type": "single",
   "options": ["自购", "租赁"], "jumps": {"租赁": "Q5"}},
  {"id": "Q2", "title": "年费用", "type": "number"}
]
```

2. `questions` 对象 / 数组，元素同上。

3. 跳题表 + 题序 + 元信息：

```json
{
  "order": ["Q1", "Q2", "Q3"],
  "titles":  {"Q1": "设备来源"},
  "types":   {"Q1": "single"},
  "options": {"Q1": ["自购", "租赁"]},
  "jumps":   {"Q1": {"租赁": "Q3"}}
}
```

4. 纯跳题表：顶层直接是 `{"Q1": {"租赁": "Q3"}}`。此时题序取 CSV 列顺序，单选题的选项可由 CSV 中出现的值补全。

规则：

- 跳转必须是**后面的题目**，目标题号必须存在，否则导入报错。
- 未在 `options` 中列出的跳转答案会自动补进选项。
- 跳题表里的题若没有对应 CSV 列，仍会出现在问卷中但没有导入答案（会有提示）。

示例见 `examples/jumps.json`。运行 `python3 -I examples/preview.py` 可预览示例的解析结果与每户路径。

## 路径与答案

答案的存储键是 `(路径, 题号)`，路径 = 到达该题之前经过的题目序列。

以示例问卷为例：

- 自购：`Q1 → Q2 → Q3 → Q4 → Q7`
- 租赁：`Q1 → Q5 → Q6 → Q7`

`Q7` 被两条路径共用，因此每户在两条路径上各有一份 `Q7` 答案：

- 在租赁路径把 `Q7` 改成 9000，切到自购路径看到的仍是自购路径原来的值；
- 切回租赁路径，`Q7` 恢复为 9000；
- 改答页底部「其他路径上保存的答案」列出当前路径之外已保存的值。

改答时若修改了前面的单选题，导致路径变化，旧路径上的字段不会再提交生效（页面会提示未保存），其答案仍保留在原路径下。

拒答记录同样按 `(路径, 题号)` 存储，与该路径上的后答绑定：

- 在逐户页给拒答题**补填实际选项**会清除拒答记录并按选项重新推演；去向与原记录相同时，后面已经保存的答案继续沿用，改走别支则只读取新路径上的答案；
- 勾选**清除拒答记录**则本题保持留空，路径在本题停止；
- 修改更前面的题绕开拒答时，记录和后答都原样保留，切回原路径即恢复；
- 下载的分析 CSV 只输出当前路径上仍生效的拒答记录，停用或已清除的留空。

## 目录

```
app/
  engine.py     跳题推演、路径存储、表单变更计算（纯 Python，无框架依赖）
  importer.py   CSV / JSON 解析与问卷构建
  storage.py    SQLite 持久化（单事务保存）
  main.py       Flask 路由
  templates/    页面
  static/       样式
examples/       示例 CSV、JSON 与预览脚本
tests/          引擎、导入、网页测试
```
